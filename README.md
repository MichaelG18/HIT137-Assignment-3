# HIT137 Assignment 3 - Image Puzzle Game

## Group Members
- Michael Ginis
- Michael Sandi
- Navaneethakrishnan Sundarrajan

## Project Overview
This repository contains the group project for HIT137 Assignment 3.

The project is an image puzzle desktop application developed using Python, Object-Oriented Programming (OOP), OpenCV and Tkinter.

## Responsibilities

### Michael Ginis - OOP and Core Game Logic
- Object-oriented program structure
- Core game state and tile logic
- Move tracking
- Correct tile detection
- Completion detection
- Hint and Solve logic

### Michael Sandi - OpenCV and Image Processing
- Image loading and resizing
- Image cropping and padding
- Grid and tile generation
- Swap, rotate and flip transformations
- Image reassembly

### Navaneethakrishnan Sundarrajan - Tkinter GUI and User Interaction
- Tkinter user interface
- Original and transformed image display
- Grid selection
- Mouse controls
- Buttons and counters
- Selection highlights and correct-tile indicators

## Integration and Testing
All group members will contribute to integrating, debugging and testing the final application.
